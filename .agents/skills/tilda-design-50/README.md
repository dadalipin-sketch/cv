# Tilda — авторский дизайн на основе 50 проектов

Самостоятельный навык для задач Валерии Екимовой. Исследование: 20 ноября 2026.

## Что внутри

- `SKILL.md` — правила применения и рабочий процесс.
- `references/projects-50.md` — 50 индивидуальных разборов с источниками.
- `references/patterns.md` — подбор решений под бизнес-задачу.
- `references/implementation.md` — Zero Block, адаптивы, анимация, SEO и MCP.
- `references/sources.json` — реестр и технические наблюдения.
- `agents/openai.yaml` — метаданные навыка для совместимого клиента.

## Использование

В этой рабочей среде навык лежит в `/workspace/skills/tilda-design-50`. Для ручного применения попросите: «Прочитай SKILL.md из tilda-design-50 и сделай сайт по этому навыку».

В клиенте с поддержкой локальных навыков установите каталог через его штатный механизм и вызовите `$tilda-design-50`. Не считайте пакет установленным, пока клиент не покажет его в списке доступных навыков. Здесь автоматическая установка в аккаунт ChatGPT недоступна. GitHub хранит постоянную копию; это не автоматическая память во всех чатах.

## Что изучено

Просмотрены 50 сохранённых превью Made on Tilda. Исходный HTML получен с HTTP 200 у 48 страниц; две дали 404/503 и разобраны по галерейным изображениям. Это визуально-структурное исследование, не полноценный аудит всех пользовательских сценариев. Не измерялись конверсия, мобильная работа, Core Web Vitals и платежи. Тексты и изображения чужих сайтов в пакет не скопированы; даны ссылки, краткие наблюдения и метаданные.

## Главное предпочтение

Не добавлять мелкие декоративные подписи, капс-рубрикаторы и нумерацию разделов по умолчанию. Только по явной просьбе Валерии.
