# Ekimova Design — прототип главной

Адаптивный чёрно-белый прототип по исходным текстам Валерии Екимовой. Без фотографий, внешних библиотек и сборки.

## Открыть

Скачайте `index.html` и откройте в браузере. Файл работает автономно.

## Состав

Главная: первый экран, два подтверждённых проекта, услуги, подход, вопросы аудитории, интерактивное сравнение заголовков, этапы, сотрудничество, передача сайта, FAQ и форма брифа. Кнопка «Показать заметки» включает пояснения к прототипу.

## Интерактивность

Мобильное меню, навигация по разделам, предвыбор формата из услуг, вкладки примеров заголовков с клавиатурным управлением, FAQ, модальная карта сайта. Форма валидирует обязательные ответы и скачивает бриф как текстовый файл. Персональные данные не отправляются и не сохраняются на сервере.

## Будущие страницы

- `/projects/` — портфолио
- `/projects/capital-yachts/` и `/projects/kosmo/` — кейсы
- `/services/landing/`, `/services/business/`, `/services/shop/` — услуги
- `/about/` — автор и подход
- `/contacts/` — контакты
- `/privacy/` — политика обработки данных

Внутренние страницы не входят в текущий прототип. Их структура показана через «Карту сайта». Ссылки кейсов ведут на существующие внешние страницы.

## Проверка

Проверены разбор HTML, уникальность идентификаторов, внутренние якоря и синтаксис JavaScript (`node --check`). Браузерная проверка не выполнена: в управляемой среде отсутствует `cua_repl.js`.

## Перед рабочим запуском

Подключить получателя заявок и опубликовать согласованную политику обработки данных. Реализовать внутренние страницы. Подставить изображения проектов и согласовать финальное визуальное оформление.
